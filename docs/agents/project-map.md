# Project map — Vibe AudioModem

Concise map of the repository as it is now. The roadmap is `TODO.md`, the vocabulary `GLOSSARY.md`, the decisions `docs/adr/` and `docs/agents/memory.md`.

**What it is:** a one-way, weak-signal data modem for radio amateurs, being rewritten from scratch. Python 3.12, NumPy/SciPy core, `uv` for dependencies, no GNU Radio. The first prototype is frozen under the git tag `legacy-v0`; see `docs/legacy/` for its documentation, and read its files with `git show legacy-v0:<path>`.

## Layout

| Path | What is there |
| :-- | :-- |
| `src/vibemodem/core/modem.py` | The candidate interface: `Modem` protocol (`modulate(message, preset)`, `demodulate(samples)`) and `Reception` (message plus optional metrics, `start_sample`), `Detection` and `Report` (what `demodulate_report` of the coded modems gives: the receptions, and the Signals found whole whose Message was not read). The rest of the core is empty so far. Imports nothing from `io`, `app`, `bench`, the network or audio libraries; enforced by a test. |
| `src/vibemodem/core/code.py` | The `Code` interface (`info_bits`, `coded_bits`, `parameters` (plain data recorded in result files), `encode(bits)`, `decode(soft values) -> bits or None`); positive soft values mean 0; `as_vector` / `as_bits` validate inputs. |
| `src/vibemodem/core/ldpc.py` | `LdpcCode`: repeat-accumulate LDPC (200 information bits, 400 coded, information bits in 4 rules each, rules placed by PEG, deterministic), encoded by a running XOR, decoded by normalised min-sum (0.8, at most 50 iterations). A test pins the code's digest. |
| `src/vibemodem/core/turbo.py` | `TurboCode`: two recursive 8-state encoders (4G polynomials) in parallel, a spread-shuffle interleaver (four fifths of the largest reachable spread, 8 for 200 bits, built deterministically, no cache), half the parity kept, tails sent, 412 coded bits; max-log-MAP decoding, extrinsic scaling 0.75, at most 8 iterations, never returns None. `rsc_encode` is the single encoder. A test pins the code's digest. |
| `src/vibemodem/core/turbo_modem.py` | `TurboModem`: the same modem with the turbo code (same airtime as the baseline). |
| `src/vibemodem/core/long_convolutional.py` | `LongConvolutionalCode`: the WSPR code (constraint length 32, rate 1/2, 31 tail bits, 462 coded bits) decoded by the Fano sequential algorithm in pure Python (threshold step 3, soft values scaled to a mean size of 2.5, 1,000 steps per bit then it gives up and returns None). A test pins the code's digest and checks the encoder against the polynomials. |
| `src/vibemodem/core/long_convolutional_modem.py` | `LongConvolutionalModem`: the same modem with that code (a Transmission 9% longer than the others). |
| `src/vibemodem/core/coded_modem.py` | `CodedModem`: what coded modems share (Frame, send order with interleaver and repetition, the reception loop). |
| `src/vibemodem/core/message.py` | The Message protocol: `Fragment(msg_id, index, total, payload)` (3 header bytes + up to 17 bytes, packed as the body of a Frame, `unpack` refuses nonsense), `split(message, msg_id)` (up to 255 Fragments, 4,335 bytes), `random_message_id`, and `Reassembler` (`add` returns a `Complete` once; `finish` returns `Incomplete` with the Fragments heard, `missing` and `runs()`; remembers the last 64 finished Messages). |
| `src/vibemodem/core/transmission.py` | `transmit(modem, message, preset, msg_id=, copies=1)` (one Frame per Fragment, each with its own Preamble; copy k starts at another Fragment) and `receive(modem, samples)` -> `Received(complete, incomplete)`, over any `Modem`. Also the 30-minute ceiling (`MAX_TRANSMISSION_SECONDS`), `frame_seconds`, `airtime_seconds`, `max_message_bytes` and `MessageTooLong`; `transmit` refuses a Message that would pass the ceiling or 255 Fragments after making the first Frame. |
| `src/vibemodem/core/presets.py` | The three Presets (`max-range`, `standard`, `fast`) as PHY profiles (`PhyProfile(tones, symbol_ms, interleave)`), `PRESETS`, `DEFAULT_PRESET`, `profile(name)`. A modem is built for one Preset (`TurboModem(preset="fast")`), `modulate` refuses another, and any setting given by hand overrides the profile (the bench sweeps do). The GFSK candidate of #12 was removed after its measurement; it lives in git history (commit `a891dee`). |
| `src/vibemodem/core/coded_mfsk.py` | `CodedMfskModem(code)`: the 8-FSK modem for any `Code`. |
| `src/vibemodem/core/ldpc_modem.py` | `LdpcModem`: the same modem with the LDPC code. |
| `src/vibemodem/core/baseline.py` | `BaselineModem`: the reference candidate, `CodedMfskModem` with the convolutional code (one fixed Frame per Transmission, up to 20 bytes, CRC-32, preamble search). Built for one Preset (default `standard`). |
| `src/vibemodem/core/mfsk.py` | `Waveform(tones, symbol_seconds)` (2/4/8/16 tones; default `STANDARD` = 8 tones 12.5 Hz apart, 80 ms symbols), continuous phase; `synthesize`, `tone_energies`, and the search for the preamble over every start time and audio frequency (`find_signals`, then `refine`). |
| `src/vibemodem/core/convolutional.py` | Rate-1/2, constraint length 7 code and its soft-decision Viterbi decoder. |
| `src/vibemodem/core/frame.py` | The fixed-size Frame: length byte, padded Message, CRC-32, whitened; `encode_frame` / `decode_frame` (None when the checksum fails). |
| `src/vibemodem/io/audio.py` | The audio layer (no DSP, mono, 48 kHz): `Audio` protocol (`list_devices`, `play`, `record`, `listen`), `DeviceInfo`, `find_device` (by number or part of a name; several matches are refused), `SoundCard` (through `sounddevice`, plays through a callback stream of its own and `stop()` is only a flag the callback looks at: `sd.stop()` from another thread corrupted PortAudio's memory and killed the application; loaded lazily so a missing library is `AudioLibraryUnavailableError`, a device that cannot do 48 kHz mono is `UnsupportedAudioError`), `InputBlocks` (what `listen` returns: a bounded queue of float32 blocks, oldest dropped and counted in `dropped`), and `FakeAudio` (scripted input, remembers what is played, optional loopback). |
| `bench/replay.py` | `python -m bench.replay FOLDER`: decodes every kept reception again with its modem and Preset; a Frame read must give the same Message, frequency (1 Hz) and SNR (1 dB), a Signal lost must still be lost; exit status 1 on a mismatch. |
| `bench/false_alarms.py` | `python -m bench.false_alarms --preset fast --hours 10 [--ssb]`: how many Signals and Messages the receiver reports in noise alone. |
| `bench/audio_check.py` | `python -m bench.audio_check --list | --input X --level 3 | --input X --output Y`: try the real sound card by hand (devices, input level, or play a Transmission while listening and receive it). |
| `src/vibemodem/io/wav.py` | `read_wav` (8/16/24/32-bit integers and floats, stereo averaged, only 48 kHz, else `WavError`) and `write_wav` (16-bit mono; refuses audio beyond full scale). |
| `src/vibemodem/io/levels.py` | `check_level(samples)` -> `LevelReport(peak, rms_dbfs, clipping, too_low, messages)`: clipping when 0.1% of samples reach 99% of full scale, too low under -50 dBFS RMS. |
| `src/vibemodem/core/spectrum.py` | `spectrum_row(block)`: the power in each of 480 bins of 5 Hz from 300 to 2700 Hz, in dB (the loudest FFT bin of each cell; -120 for silence). |
| `src/vibemodem/app/heard.py` | `Heard` (a Message heard whole or in part, with `snr_db` (mean of its Fragments), `frequency_hz` (lowest tone of the first Fragment), `offset_hz`, `sync_score` (the lowest)), `Undecoded` (a Signal found whole whose Message was not read), `SpectrumRows`, `Quality` and `summarize`. |
| `src/vibemodem/app/store.py` | `ReceptionStore(directory, max_bytes)`: a reception is a 16-bit mono 48 kHz WAV and a JSON of the same name, written last by renaming (`save`, `receptions`, `usage`, `clear`, `set_max_bytes`); every look at the folder is under the lock; only regular files named like ours (UTC time in the name) are counted, read or deleted, and a damaged JSON is skipped; unfinished receptions are cleaned away; the oldest go first when the bound is passed (WAV and JSON together, JSON counted); nothing is made on disk until the first `save`. `default_directory()` by platform (XDG on Linux, Application Support on macOS, LOCALAPPDATA on Windows). |
| `src/vibemodem/app/keeper.py` | `Keeper(store)`: keeps each Frame read and each Signal lost once (first pass with 3 s of sound after it, or the last pass; a reception that cannot be kept is given up on once and reported), with 3 s around it, cut on the grid of the search of its window so that replaying it reads the same figures. |
| `src/vibemodem/app/receiver.py` | `Receiver(audio, make_modem)`: listening. A thread draws a row of spectrum per 0.5 s block and decodes a sliding window (150 s, every 10 s, and once more at the end) with `demodulate_report`; keeps one `Reassembler` for the session, the quality of each Fragment (the clearest sighting counts), the last 20 undecoded Signals (listed once; a Signal later read is removed, a lost one next to a Frame that was read is a side peak, a Frame cut by the start of a window is not judged), the last 100 Messages, the last 120 rows. Times are by the audio clock (start of the listening + sound heard). With a store and `set_keeping(True)` it hands what it found to its `Keeper`. |
| `src/vibemodem/app/service.py` | `ModemService(audio)`: settings (`Settings(preset, input_device, output_device)`, changed all together or not at all, refused while sending or listening: `SettingsError`, `BusyError`), `send(text, copies, frequency_hz)` (the lowest tone, within the Preset's range; builds the Transmission first so a Message that is too long is refused before any sound, then plays in a thread), `cancel()` (repeats `audio.stop()` until the thread ends), `start_listening()` / `stop_listening()` (delegated to the `Receiver`), `received()` (the last 100 Messages heard whole, then those heard in part), `storage()` / `set_storage(keep, limit_mb)` (together or not at all; allowed while listening) / `clear_receptions()` (delegated to the Receiver's store), `undecoded()` (the last 20 Signals found but not read, listed once however many passes see them), `spectrum(since)` (rows of the waterfall, the last 120 kept), `status()`, `estimate(text, copies, frequency_hz)` (fragments, airtime, largest Message, the refusal that send would give, the frequency range; no sound), `close()` (idempotent). No HTTP. |
| `src/vibemodem/app/api.py`, `page.html`, `main.py` | The local API (`create_app(service)`): `/api/status`, `/api/devices`, `/api/settings`, `/api/send`, `/api/estimate`, `/api/cancel`, `/api/listen/start|stop`, `/api/received` (with `undecoded`), `/api/storage` (GET, POST `keep` and `limit_mb` only: the folder is not settable from the page), `/api/storage/clear`, `/api/spectrum?since=N`, `/api/selftest`, `/api/quit`; errors are 422 (invalid, `MessageTooLong`), 409 (busy), 503 (audio); a middleware refuses a Host that is not loopback (421) and an Origin that is not its own (403). `page.html` is the page (HTML + JS in one file next to the module, no build step, offline; the packaging spec and `package-data` ship it). `main.py`: `make_server` (127.0.0.1 only, closes the service on shutdown) and `main` (`python -m vibemodem.app`, `--port`, `--no-browser`). |
| `bench/channel.py` | Channel simulator: `apply_channel(samples, ChannelConfig, seed)`; fading, frequency offset, white noise at an SNR in 2,500 Hz, impulses, 300–2,700 Hz filter, clipping, clock drift. All off by default, each with its own seeded stream. |
| `bench/toy.py` | `ToyModem`: coherent BPSK at 100 bit/s, no sync, no coding. Exists only to validate the bench against the textbook error curve. |
| `bench/threshold.py` | `measure_curve`, `success_threshold` (lowest SNR reaching 95%, with every higher tested SNR also passing) and the command `python -m bench.threshold --modem pkg.mod:Class --out file.json`. |
| `bench/bandwidth.py`, `bench/sweep.py`, `bench/settings.py` | `python -m bench.bandwidth` (and `--preset` builds the modem for that Preset) (occupied bandwidth at -20 dB), `python -m bench.sweep` (tones x symbol duration: bandwidth, transmission length, thresholds at 95/90/80%), and the shared `--set name=value` parsing. |
| `bench/code_curves.py` | `frame_error_rate(code, ebn0_db, frames, seed)` and `python -m bench.code_curves --code pkg.mod:Class [--set name=value]`: share of frames a code loses on white noise against Eb/N0 (validated against Q(sqrt(2 Eb/N0)) for a single uncoded bit). |
| `bench/speed.py` | `measure_speed` and `python -m bench.speed --modem pkg.mod:Class`: median time to receive a ~24 s recording, real-time factor, and the modem's code alone; saves it with the machine's description. |
| `bench/report.py` | Self-contained HTML report (inline SVG chart, Wilson 95% intervals, ranking, not-comparable notice) from result JSON files: `render_report`, and the command `python -m bench.report a.json b.json --out r.html`; also reached through `--html` on the threshold command. |
| `packaging/` | `vibemodem.spec` (PyInstaller, windowed), `entry.py`, `smoke_test.py` (run against the built executable in CI). |
| `tests/` | `test_layers.py` (layers importable, core stays pure), `test_channel.py`, `test_service.py`, `test_api.py`, `test_audio.py`, `test_wav.py`, `test_levels.py`, `test_audio_check.py`, `test_toy_modem.py`, `test_threshold.py` (threshold logic, toy modem vs theory), `test_threshold_command.py`, `test_report.py`, `test_report_command.py`, `test_mfsk_modems.py` (both modems: round trip, unknown start and frequency, never-delivered cases), `test_codes.py` (the contract of every Code), `test_ldpc.py`, `test_turbo.py`, `test_long_convolutional.py`, `test_speed.py`, `test_code_curves.py`; `fake_modems.py` holds stand-in candidates. |
| `.github/workflows/` | `ci.yml` (ruff + pytest on Linux/Windows for every push, plus macOS on pull requests), `package.yml` (build, smoke-test and upload Windows/macOS artifacts). |
| `docs/` | `adr/` (decisions), `packaging/` (spike findings, manual check procedure), `legacy/` (prototype docs), `references/` (papers), `agents/` (this folder). |

## Commands

```bash
uv sync --locked --all-extras              # set up
uv run ruff check . && uv run ruff format --check . && uv run pytest
uv run python -m vibemodem.app             # run the spike app
```
