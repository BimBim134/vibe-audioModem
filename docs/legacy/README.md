# Legacy prototype documentation

These two documents describe the first prototype (GMSK at 200 baud on GNU Radio), which is no longer in the tree. Its code is frozen under the git tag `legacy-v0`; the file paths and line numbers quoted in these documents refer to that tag. Read a file with `git show legacy-v0:<path>`.

- `doc.md`: code walkthrough of the prototype.
- `architect_opinion.md`: architecture review that motivated the rewrite (see ADR 0001).
